Install Arc TV on Android TV

Arc TV for Android TV is installed with the free Downloader app and a short code, 2368012. It works on Android TV and Google TV devices.

What you need

  • An Android TV or Google TV device with an internet connection
  • Your TV remote
  • A few minutes

Step by step

  1. Install the Downloader app

    Open the Google Play Store on your TV, search for Downloader (by AFTVnews) and install it.

  2. Open Downloader and allow access

    Open Downloader. If it asks for permission to access files, choose Allow.

  3. Enter the code

    In the URL box, type 2368012 and select Go. Downloader fetches the latest Arc TV app.

  4. Allow installing from Downloader

    When the download finishes, Android may say Downloader isn’t allowed to install apps. Choose Settings, turn on Allow from this source, then go back. On some devices this is under Settings → Apps → Security & restrictions → Unknown sources.

  5. Install and sign in

    Select Install, then Open. Sign in with your Arc TV account, or scan the QR code with your phone.

Updating

To update Arc TV, repeat steps 3 to 5. The code 2368012 always points to the latest release.

Troubleshooting

The code doesn’t work

Check the digits (2368012) and that you typed it in the URL box. You can also download the app from the releases page.

Install is blocked

Repeat step 4 and make sure installing from Downloader is allowed.

Downloader isn’t in the Play Store

Some devices hide it. Make sure the TV is up to date and signed in to a Google account, then search again.

Arc TV doesn’t host, store or provide any media. Use it only with content you have the right to access.
