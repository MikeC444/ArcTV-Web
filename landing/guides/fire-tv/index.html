Install Arc TV on Fire TV

Arc TV for Fire TV is installed with the free Downloader app and a short code, 2368012. It takes about five minutes and works on Fire TV Sticks and other Fire TV devices.

What you need

  • A Fire TV with an internet connection
  • Your Fire TV remote
  • A few minutes

Step by step

  1. Install the Downloader app

    On your Fire TV Home screen, choose Find, then Search, and look for Downloader (the orange icon, by AFTVnews). Select it and choose Download or Get to install it from the Amazon Appstore.

  2. Let Downloader install apps

    Go to Settings → My Fire TV → Developer options → Install unknown apps and turn Downloader on. If you don’t see Developer options, open Settings → My Fire TV → About and select your device name seven times, then go back. Menu names vary a little between Fire OS versions.

  3. Enter the code

    Open Downloader. In the URL box, type 2368012 and select Go. Downloader fetches the latest Arc TV app.

  4. Install Arc TV

    When the download finishes, select Install, then Open. You can delete the installer file afterwards if Downloader offers to.

  5. Sign in

    Sign in with your Arc TV account, or scan the QR code with your phone. Your list, progress and settings are the same as on the web app.

Updating

To update Arc TV, repeat steps 3 and 4. The code 2368012 always points to the latest release.

Troubleshooting

The code doesn’t work

Check the digits (2368012) and that you typed it in the URL box. You can also download the app from the releases page.

Install is blocked

Repeat step 2 and make sure Downloader is switched on under Install unknown apps.

I can’t find Downloader

Search from the Home screen and check the spelling. If it still doesn’t appear, restart your Fire TV and try again.
